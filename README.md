# Nasser Janzal Portfolio

A polished bilingual portfolio, built to present brand partnerships, services, impact, and booking opportunities.

## Main features

- English and Arabic experiences with right-to-left layouts for Arabic content.
- Partnership timeline, brand showcase, services, impact metrics, and visual storytelling.
- Enquiry form powered by Resend: management receives each enquiry and the sender receives a confirmation email.
- Floating WhatsApp chat for direct contact.
- Responsive, optimized Next.js images and motion-rich interactions.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Email configuration

Create `.env.local` from `.env.example` and add your Resend credentials and recipient email. Keep `.env.local` private; it is excluded from Git.
